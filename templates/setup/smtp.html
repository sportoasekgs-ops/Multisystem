E-Mail-Konfiguration

Wähle einen E-Mail-Provider für Buchungsbestätigungen. Dieser Schritt ist optional und kann übersprungen werden.

ℹ️ Für Gmail: Nutze ein App-Passwort (Google-Konto → Sicherheit → App-Passwörter). Normale Gmail-Passwörter werden von Google blockiert.
⚠️
🔒
Microsoft hat Basic Authentication deaktiviert!
Normales Passwort funktioniert nicht mehr mit Outlook / Office365.
Lösungen:
  1. App-Passwort erstellen: Microsoft-Konto → Sicherheit → App-Passwörter (erfordert aktivierte 2-Faktor-Auth)
  2. IT-Admin bitten, SMTP AUTH für das Postfach im Exchange Admin Center zu aktivieren
  3. Resend oder Brevo als alternativen E-Mail-Anbieter verwenden (kostenlos, einfach einzurichten, ideal für Render)

Falls leer, wird der SMTP-Benutzername verwendet

🧪 SMTP-Verbindung testen

☁️ Resend ist eine Cloud-E-Mail-Alternative zu Gmail/SMTP. Registriere dich kostenlos auf resend.com, erstelle einen API-Key und gib ihn hier ein.

Zu finden unter resend.com → API Keys

Muss eine bei Resend verifizierte Domain verwenden (oder onboarding@resend.dev zum Testen)

📨 Brevo sendet per HTTP-API. Registriere dich kostenlos auf brevo.com, erstelle einen API-Key und gib ihn hier ein. Du musst in Brevo deine Absenderadresse bestätigen.

Zu finden unter brevo.com → SMTP & API → API Keys

Muss bei Brevo als Absender verifiziert/bestätigt sein.

An diese Adresse werden neue Buchungsbenachrichtigungen gesendet
