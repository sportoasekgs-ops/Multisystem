Die Datenbank-URL wird in der lokalen Datei buchungssystem_local.json gespeichert. Die App startet nach dem Speichern automatisch neu.

{% if db_url_masked %}
✅ Aktuell konfiguriert: {{ db_url_masked }}
{% else %}

{% endif %}

Aus Sicherheitsgründen wird die aktuelle URL nicht angezeigt. Nur ausfüllen wenn du die URL ändern möchtest.

Hinweise zur Datenbank

  • Format: postgresql://BENUTZER:PASSWORT@HOST:PORT/DATENBANKNAME
  • Unterstützt: PostgreSQL (Neon, Supabase, Render, eigener Server)
  • Bei Render: Interne DB-URL aus dem Render-Dashboard kopieren
  • Die URL wird lokal in buchungssystem_local.json gespeichert (nicht in der Datenbank)

🔴 System komplett zurücksetzen

Diese Funktion löscht alle Daten unwiderruflich:

  • Alle Buchungen und Benachrichtigungen
  • Alle Benutzerkonten (Lehrer, Admins)
  • Alle Slot-Sperrungen und Slot-Namen
  • Alle Konfigurationen (Branding, SMTP, IServ, Kurse, Klassen, Stunden)
  • Die gesamte Systemkonfiguration → Setup-Wizard startet neu
⚠️ Diese Aktion kann NICHT rückgängig gemacht werden!
Machen Sie vorher ein Backup der Datenbank, falls Sie die Daten sichern möchten.

Was passiert danach?

  • Sie werden automatisch zum Einrichtungs-Assistenten weitergeleitet
  • Der Setup-Wizard führt Sie Schritt für Schritt durch die Neu-Einrichtung
  • Alle Lehrer müssen sich nach dem Reset neu einloggen
  • Die Datenbank-URL bleibt erhalten (nur die Inhalte werden gelöscht)

🧪 Demo-Modus DEMO

Im Demo-Modus werden Beispiel-Buchungen angezeigt, E-Mails werden nicht versendet und ein oranges Demo-Badge erscheint in der Navigationsleiste. Ideal zum Testen oder Vorführen ohne echte Daten zu verändern.

Demo-Modus {{ 'ist aktiv' if demo_mode else 'ist deaktiviert' }}

{{ 'Fake-Buchungen werden angezeigt, E-Mails werden unterdrückt.' if demo_mode else 'Normaler Betrieb. Echte Daten und E-Mails.' }}

Was passiert im Demo-Modus?

  • In der Wochenansicht werden 3 Beispiel-Buchungen angezeigt
  • Neue Buchungen können nicht erstellt werden (Hinweis wird angezeigt)
  • E-Mails werden nicht verschickt (nur als Log ausgegeben)
  • Ein oranges DEMO-Badge erscheint in der Navigationsleiste
  • Alle bestehenden echten Daten bleiben unverändert
